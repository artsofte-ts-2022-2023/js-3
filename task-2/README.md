Напишите функцию `lock(sourceObj, keys)`, где

-   `sourceObj` - исходный объект. Может содержать `number`, `string`, `boolean`, а также другие объекты такого же типа.
-   `keys` - массив названий ключей, значения которых нужно сделать недоступными для изменения. Если значение данного ключа - объект, значит, нужно сделать недоступными для изменения все его ключи. Если массив содержит ключ, которого нет в объекте, то нужно выбросить ошибку с описанием `NoneKeyError`.
-   Если в ключах попадается значение с типом, отличающимся от `string`, ключи не переданы или передан пустой массив, нужно выбросить ошибку `Wrong keys argument`.
-   Если не передан объект или тип значения в аргументе не является объектом, нужно выбросить ошибку `Uncorrect source object`.

Пример:

const obj = {
    a: {
        b: 2,
        c: true,
    },
    d: 'hello',
};

lock(obj, ['a.b', 'd']);
```
