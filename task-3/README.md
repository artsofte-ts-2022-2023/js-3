Ваш первый npm-пакет. Нужно создать любое приложение, упаковать его в пакет и выложить в npm. Обязательное условие: в проекте должен быть файл `README.md`, в котором будут указаны ваши имя и фамилия, а также ссылка на нашу образовательную платформу.

На платформу нужно выложить JS-файл со следующим содержимым:

```js
export const npmPackageLink = () => {
    return 'https://www.npmjs.com/package/<yourpackage>';
};
```
